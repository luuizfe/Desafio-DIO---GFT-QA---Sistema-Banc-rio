
# 🏦 Sistema Bancário em Java (POO)

Projeto simples em **Java puro** que simula um sistema bancário utilizando **Programação Orientada a Objetos**, com regras de negócio realistas para contas **Corrente** e **Poupança**.

---

## 🚀 Funcionalidades

* Criação de clientes e contas
* Conta Corrente com:

  * Taxa de saque
  * Taxa de transferência
  * Cheque especial
  * Mensalidade
* Conta Poupança com:

  * Limite de saques mensais
  * Transferências sem taxa
  * Rendimento mensal
* Transferência entre contas
* Validações de regras de negócio
* Relatório geral do banco
* Extrato por conta

---

## 🧠 Conceitos aplicados

* Encapsulamento
* Herança
* Polimorfismo
* Classes abstratas
* Exceções
* Streams (Java)
* Boas práticas de OO

---

## 🛠️ Tecnologias

* Java 17+ (compatível com Java 8)
* Lombok
* IDE: NetBeans / IntelliJ / Eclipse

---

## ▶️ Como executar

1. Clone o projeto
2. Importe na sua IDE Java
3. Garanta que o **Lombok** está configurado
4. Execute a classe `Main`

---

## 📌 Observações

* O projeto não utiliza Spring
* Código organizado e fácil de evoluir para testes ou camadas de serviço
